Who's Playing?

Profiles & progress stay on this device only (localStorage) — no accounts, no passwords, no cloud sync. Use Parent / Progress export & import to hand off between devices.

How it works

  • Create a named explorer and pick an age track (5–6, 7–8, or 9–10)
  • Quick cosmic warm-up (diagnostic) — no pressure!
  • Mission Map: explain → example → practice → check across ~28–30 lessons per track
  • Mastery & spaced review — hit ~80% on the check to master; reviews pop up later so skills stick
  • Missed the check? Retry weak spots before a full redo — Einstein coaches gently
  • Multiple kids on one device — each keeps separate stars (device-local only)
  • Install / offline — after one online visit, Chromium can install this PWA; play offline from the cache
  • Multi-device — export all profiles on Progress, import on another device (merge or replace) until real sync exists
